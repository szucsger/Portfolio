# Simple Landing Page

Egy reszponzív, Bootstrapre épülő hiking landing page, amelyet a layout, a vizuális hierarchia és a mobilbarát felépítés gyakorlására készítettem. A projekt célja egy letisztult, természetközeli bemutató oldal felépítése volt.

## Áttekintés

A landing page egy utazós-hiking témájú bemutató oldal. A fő hangsúly a vizuális blokkok összerendezésén, a hero szekción, a tartalmi kártyákon és a reszponzív viselkedésen van.

## Fő funkciók

- erős, képes hero szekció
- bemutató és tartalmi blokkok
- social link megjelenítés
- kártyás, vizuálisan tagolt layout
- reszponzív működés mobilnézetre is
- Bootstrap alapú grid és komponens használat
- egyedi CSS-es finomhangolás

## Használt technológiák

- HTML5
- CSS3
- Bootstrap 5

## Projektstruktúra

- [hiking.html](hiking.html) - a fő oldal
- [CSS/hiking.css](CSS/hiking.css) - egyedi stílusok
- [imgs](imgs) - képek és vizuális assetek

## Tanulási cél

Ezzel a projekttel a következőket gyakoroltam:

- Bootstrap alapú layout építés
- reszponzív tervezés
- szekciók vizuális tagolása
- egyedi CSS finomhangolás
- képes landing page felépítése
