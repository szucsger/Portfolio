# Szücs Gergely portfóliója

Ez a repo a jelenlegi személyes portfólió oldalamat tartalmazza, amely a GitHub Pages felületén fut. Az oldal célja, hogy röviden bemutassa a frontend fókuszomat, a tanulási szemléletemet, a használt technológiákat, valamint néhány saját mini-projektemet.

Az oldal egy modern, reszponzív landing page, amely a következő fő részekből áll:

- bemutatkozó hero szekció
- tanulási szemlélet és erősségek
- technológiai stack
- beágyazott mini-projekt előnézetek
- kapcsolatfelvételi blokk
- lezáró CTA és lábléc

## Mini projektek

### JavaScript UFO Catcher

Egy egyszerű böngészős játék, amelyet DOM-manipuláció, animációk és játékmenet-logika gyakorlására készítettem.

### TypeScript Statistics Dashboard

Egy TypeScript alapú dashboard, amely adatkezelést, statisztikákat, szűrést, rendezést, localStorage mentést és Chart.js diagramokat mutat be.

### Angular Practice Project

Jelenleg előkészített helyfoglaló egy későbbi Angular projekthez, amely a komponensalapú gondolkodást és a moduláris fejlesztést fogja támogatni.
